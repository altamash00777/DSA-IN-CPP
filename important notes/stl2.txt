4. Associative Containers

Store elements in sorted order.

Container	Description
set	Unique sorted elements
multiset	Duplicate allowed
map	Key-value (unique keys)
multimap	Duplicate keys allowed
4.1 Set

Stores unique values

Sorted automatically

Functions:

insert()

erase()

find()

count()

4.2 Map

Stores key-value pairs

Keys are unique

Functions:

insert()

erase()

find()

operator[]

5. Unordered Containers

Container	Description
unordered_set	Unordered unique values
unordered_map	Unordered key-value

9. lower_bound & upper_bound

lower_bound(x) → first element >= x

upper_bound(x) → first element > x

Used in sorted containers

10. Functors (Function Objects)

Objects that behave like functions

Used in sorting & priority queue

Example:

greater<int>()

less<int>()
